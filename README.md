# Personal Project Showcase App

A responsive React single page application that allows users to add, view, search, and delete portfolio projects.

## Features

- View a list of projects
- Add new projects using a form
- Search projects dynamically
- Delete projects
- Responsive layout for desktop and mobile
- Component-based React structure

## Components

- `Header` - Displays the page title and introduction
- `ProjectForm` - Handles adding new projects
- `SearchBar` - Filters projects based on user input
- `ProjectList` - Displays all matching projects
- `ProjectCard` - Displays individual project details

## Technologies Used

- React
- Vite
- JavaScript
- CSS
